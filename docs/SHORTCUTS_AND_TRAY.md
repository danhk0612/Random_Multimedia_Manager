# 단축키 / 즉시 종료 / 전체 숨김 / 트레이 사양

## 1. 목적

Random Multimedia Manager는 일반 뷰어 단축키 외에도 프로그램 전체 상태를 즉시 제어하는 전역 동작이 필요하다.

핵심 긴급 동작:

- 프로그램 즉시 종료
- 프로그램 전체 숨김 + 재생 정지/음소거

두 동작은 일반 뷰어 단축키보다 우선순위가 높아야 한다.

## 2. 단축키 범위

단축키는 두 종류로 구분한다.

### 앱 내부 단축키

프로그램 창이 활성화된 동안만 동작.

예:

- 이전/다음 페이지
- 재생/일시정지
- Seek
- 즐겨찾기
- 삭제
- 이전/다음 랜덤

### 전역 단축키

프로그램이 포커스를 잃었거나 최소화/트레이 상태여도 동작.

대상:

- 즉시 종료
- 전체 숨김 + 음소거
- 전체 숨김 상태 복원

Windows 전역 단축키는 `RegisterHotKey` 또는 동등한 방식으로 구현을 검토한다.

## 3. 기본 원칙

- 모든 단축키는 설정에서 변경 가능해야 한다.
- 중복 단축키는 저장 전에 감지한다.
- Windows 또는 다른 프로그램에서 이미 점유한 전역 단축키는 등록 실패를 사용자에게 알려야 한다.
- 긴급 단축키는 단일 문자보다 Ctrl/Alt/Shift 등 조합키를 기본으로 권장한다.
- 전역 단축키 기능 자체를 끌 수 있어야 한다.

## 4. 프로그램 즉시 종료

사용 목적:

- 확인창 없이 프로그램을 매우 빠르게 종료
- 전체화면, 재생 중, 최소화 상태와 관계없이 동작

초기 정의:

```text
전역 단축키 입력
→ 새 작업 시작 차단
→ 현재 영상 재생/오디오 즉시 중단
→ 이미 진행 중인 짧은 DB transaction만 안전 종료
→ 현재 Pending 감상 기록은 새로 확정하지 않음
→ 창/트레이 종료
→ 프로세스 종료
```

중요:

- 이 기능은 `Process.Kill()`을 무조건 호출하는 의미의 비정상 종료로 구현하지 않는다.
- DB 손상 위험을 피하면서 UI 확인과 일반 종료 절차를 최대한 생략하는 `Fast Exit`로 구현한다.
- 프로그램 자체가 완전히 멈춘 경우 앱 내부 단축키로 자기 자신을 강제 Kill하는 것은 신뢰할 수 없으므로 별도 문제다.

설정 옵션 후보:

- 즉시 종료 전역 단축키 사용 ON/OFF
- 단축키 지정
- 현재 Pending 감상 기록 처리
  - 기록하지 않음 (기본)
  - 정상 종료처럼 기록
- 현재 PlaybackProgress 저장
  - 저장 (기본)
  - 저장하지 않음

## 5. 전체 숨김 + 음소거

사용 목적:

- 프로그램의 모든 시각적 표시를 즉시 숨김
- 현재 영상 소리를 즉시 차단
- 필요 시 같은 전역 단축키로 복원

초기 동작:

```text
전역 단축키 입력
→ 모든 앱 창 숨김
→ 전체화면 해제 여부와 관계없이 화면에서 제거
→ 영상 재생 일시정지
→ 앱 오디오 음소거
→ 작업표시줄 버튼 숨김
→ 설정에 따라 트레이 아이콘 유지/숨김
```

이 상태를 `Quick Hide Mode`로 정의한다.

## 6. Quick Hide 복원

복원 경로:

- 같은 전역 단축키 재입력
- 별도의 `복원` 전역 단축키
- 트레이 아이콘 메뉴의 `보이기` (트레이 아이콘 유지 설정일 때)

복원 시 옵션:

### 영상 재생

- 계속 일시정지 상태 유지 (기본 권장)
- 숨기기 전 재생 중이었다면 자동 재생

### 음소거

- 숨기기 전 음소거 상태/볼륨으로 복원 (기본 권장)
- 계속 음소거 유지

### 창 상태

- 숨기기 직전 창/전체화면 상태 복원
- 일반 창으로 복원

## 7. 트레이 아이콘 숨김 옵션

Quick Hide 시:

```text
트레이 아이콘
- 유지
- 함께 숨김
```

`함께 숨김`은 복원 경로가 사라질 수 있으므로 다음 조건이 필요하다.

- 복원 가능한 전역 단축키가 정상 등록되어 있을 때만 허용

전역 단축키 등록 실패 상태에서는 트레이 아이콘까지 숨기는 설정을 적용하지 않는다.

## 8. 일반 트레이 동작

프로그램은 시스템 트레이 아이콘을 지원한다.

설정:

### 최소화 버튼 동작

- 작업표시줄로 최소화
- 트레이로 최소화

### 닫기(X) 버튼 동작

- 프로그램 종료
- 트레이로 숨김
- 매번 묻기

### 프로그램 시작

- 일반 창으로 시작
- 트레이에서 시작
- 이전 상태 복원

### Windows 시작 시 실행

- ON/OFF
- 시작 시 트레이로 실행 옵션

## 9. 트레이 클릭 동작

설정 가능 후보:

### 단일 클릭

- 아무 동작 없음
- 보이기/숨기기 토글

### 더블 클릭

- 보이기/숨기기 토글
- 메인 화면 열기

초기 기본값은 플랫폼 관례에 맞게 단순하게 정한다.

## 10. 트레이 메뉴

권장 기본 메뉴:

```text
Random Multimedia Manager
────────────────────────
보이기 / 숨기기
현재 재생 일시정지 / 재생
음소거 ON/OFF
다음 랜덤
이전 랜덤
즐겨찾기 토글
────────────────────────
Quick Hide
설정
────────────────────────
종료
```

현재 미디어가 없으면 재생/다음/즐겨찾기 등 해당 메뉴는 비활성화한다.

만화 감상 중에는 `재생/일시정지` 대신 적용 가능한 메뉴만 표시하거나 비활성화한다.

## 11. 트레이 상태 표시

트레이 Tooltip 후보:

```text
Random Multimedia Manager
[Video] movie.mkv
Paused / Muted
```

너무 긴 경로는 표시하지 않는다.

Quick Hide 상태에서는 설정에 따라 일반적인 프로그램명만 표시할 수 있다.

## 12. 트레이 메뉴에서 삭제

초기 버전에서는 권장하지 않는다.

이유:

- 실수 가능성이 큼
- 휴지통/영구 삭제 선택 UI가 필요함

삭제는 뷰어/플레이어 안에서 수행하는 것을 기본으로 한다.

후속 기능으로 명시적 확인과 함께 추가 가능하다.

## 13. 권장 기본 단축키 초안

실제 기본키는 구현 시 충돌 여부를 보고 확정한다.

### 공통 앱 내부

- `F`: 즐겨찾기 토글
- `N`: 다음 랜덤
- `B`: 이전 랜덤
- `Delete`: 삭제 확인
- `F11`: 전체화면
- `Esc`: 전체화면 해제 / 오버레이 닫기

### 영상

- `Space`: 재생/일시정지
- `Left/Right`: 시간 이동
- `Up/Down`: 볼륨
- `M`: 음소거

### 만화

- `Left/Right`: 이전/다음 페이지
- `PageUp/PageDown`: 이전/다음 페이지 또는 스크롤

### 전역 긴급 기능

기본값은 사용자 환경 충돌 가능성이 높으므로 구현 시 확정하며 설정 UI에서 명확히 표시한다.

- Fast Exit
- Quick Hide/Restore

## 14. 단축키 설정 UI

각 항목은 다음 상태를 표시한다.

```text
기능                 단축키                 범위
즐겨찾기             F                      앱 내부
다음 랜덤            N                      앱 내부
즉시 종료            Ctrl+Alt+...           전역
전체 숨김/복원       Ctrl+Shift+...         전역
```

필수 기능:

- 키 조합 녹화 입력
- 중복 감지
- 기본값 복원
- 해당 단축키 비활성화
- 전역 등록 성공/실패 표시

## 15. Quick Hide 상태와 기록

Quick Hide는 파일을 벗어난 것이 아니다.

따라서:

- ViewHistory를 확정하지 않음
- 현재 랜덤 세션 유지
- PlaybackProgress 계속 유지 가능
- 복원하면 동일 파일로 돌아감

Quick Hide 중 프로그램 종료가 발생하면 일반 종료/즉시 종료 정책에 따라 Pending 기록을 처리한다.

## 16. 알림 정책

Quick Hide와 Fast Exit는 긴급 동작이므로 화면 중앙 확인창을 띄우지 않는다.

Quick Hide 성공 피드백은 선택적으로:

- 트레이 Balloon/Toast 없음 (기본)
- 짧은 소리 없음 (기본)

즉 동작 자체가 조용해야 한다.

일반 트레이 기능에서는 업데이트/스캔 완료 등의 알림을 옵션으로 둘 수 있다.

## 17. 다중 창 정책

프로그램이 설정창, 파일정보창, 메인창, 전체화면 뷰어 등 여러 창을 갖더라도 Quick Hide는 **프로세스가 소유한 모든 사용자 창**을 한 번에 숨겨야 한다.

복원 시 숨기기 전 보이던 창 상태를 기록해 되돌릴 수 있는 구조를 권장한다.

## 18. 예외 상황

### 전역 단축키 등록 실패

- 설정 화면에 실패 표시
- 로컬 앱 단축키로 자동 대체했다고 오해시키지 않음

### Quick Hide 중 트레이 아이콘도 숨김 + 복원키 실패

이 상태가 발생하지 않도록 설정 적용 전 검증한다.

### 영상 엔진 음소거 실패

창 숨김은 진행하되 오류 로그를 남긴다. 복원 후 상태를 사용자에게 확인 가능하게 한다.

### 앱 종료 중 Fast Exit 재입력

중복 종료 요청을 무시하고 기존 종료 절차를 완료한다.
