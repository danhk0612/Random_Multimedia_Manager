# 단축키 및 트레이 경계

## 확정

- 일반 뷰어/플레이어 조작을 키보드로 제공한다.
- 빠른 종료와 모든 앱 표시 숨김+앱 음소거에 즉시 접근한다.
- 여러 앱 창이 있다면 메인 창만 숨기는 구현으로 완료 처리하지 않는다.
- Quick Hide 자체로 감상 기록을 확정하지 않는다.
- 트레이에서 표시/숨김/복원 및 종료에 접근할 구조와 최소화/닫기/시작 동작 옵션을 제공한다.

## 설계 방향

사용자는 빠르고 오류를 피하는 종료를 원하며, 먼저 모두 숨김+음소거 후 보이지 않게 종료하는 순서를 제안했다. 이 방식을 권장 설계 방향으로 삼는다. 종료는 감상 제외 명령이 아니며 정상 감상 기록 정책을 적용한다. 키·트레이·복원 기본값은 Astra에 위임되었다.

## 세부 설계 대기

종료 수준·Pending 처리, 일시정지, 작업표시줄/트레이 표시, 복원 경로와 재생/음소거/창 복구, 키 조합·전역 범위·기본 활성화, 트레이 메뉴/기본값은 docs/DECISIONS.md D03/D04의 위임 범위 안에서 T14가 결정한다.
이 문서는 이전의 강제 pause, 작업표시줄 제거, 같은 키 복원, Pending 기본 폐기를 확정 요구사항으로 유지하지 않는다.

## 구현 검토 사항

- 전역 키 등록을 선택하면 등록 실패·중복·해제와 사용자 설정을 검증한다.
- 트레이까지 숨기기로 결정하면 사용 가능한 복원 경로가 확보되어야 한다.
- 숨김 중 새 대화상자 노출, 전체화면, 다중 창, 이미 음소거/정지된 영상의 복원을 검증한다.
- 종료 도중 진행 중 DB 작업과 미디어 리소스 해제를 함께 검토한다.
- T14에서 상태 전이와 선택 정책을 문서화한 다음 T15/T16을 구현한다.

기존 제안 키(F/N/B/Delete/F11/Esc, Space/방향키/M 등), 트레이 재생·음소거·이전/다음·즐겨찾기 메뉴, 키 녹화·기본값 복원 UI는 후보이며 최종 키/메뉴를 뜻하지 않는다.
