# 만화 뷰어 / 영상 플레이어 사양

## 1. 공통 원칙

만화와 영상은 서로 다른 렌더링 엔진을 사용하더라도 다음 UX를 공통으로 제공한다.

- 현재 파일명/분류 확인
- 즐겨찾기 토글
- 랜덤 대상 제외 토글
- 이번 감상 기록 제외 토글
- 이전 랜덤 항목
- 다음 랜덤 항목
- 파일 정보
- 탐색기에서 보기
- 삭제
- 전체화면
- 공통 단축키
- 전체화면 컨트롤 자동 숨김

뷰어 타입이 바뀌어도 랜덤 세션은 끊기지 않는다.

예:

```text
만화 A → 영상 B → 만화 C
```

## 2. 만화 뷰어 - 초기 지원

### 압축 형식

필수:

- ZIP
- CBZ

후속:

- RAR / CBR
- 7z
- 이미지 폴더

### 이미지 형식

압축 내부의 일반 이미지 포맷을 읽을 수 있어야 한다.

우선 대상:

- JPG/JPEG
- PNG
- WEBP
- BMP
- GIF 정적 프레임

실제 지원 범위는 선택한 이미지 디코더가 안정적으로 처리하는 범위에 맞춘다.

## 3. 압축 파일 처리

전체 압축을 임시 폴더에 풀지 않는 것을 기본으로 한다.

```text
Archive open
→ Entry 목록 수집
→ 이미지 Entry만 필터
→ Natural Sort
→ 현재/인접 페이지만 필요 시 decode
```

대용량 압축에서도 메모리 사용량이 페이지 수에 비례해 무제한 증가하지 않아야 한다.

## 4. 페이지 정렬

반드시 Natural Sort를 사용한다.

```text
잘못된 정렬:
1.jpg
10.jpg
11.jpg
2.jpg

원하는 정렬:
1.jpg
2.jpg
10.jpg
11.jpg
```

폴더 경로가 포함된 ZIP은 내부 폴더 구조와 파일명을 함께 고려하되 사람이 기대하는 순서가 유지되도록 한다.

## 5. 만화 표시 모드

필수:

- 한 페이지
- 두 페이지
- 세로 연속 스크롤

읽기 방향:

- 왼쪽 → 오른쪽
- 오른쪽 → 왼쪽

두 페이지 모드에서는 읽기 방향에 따라 페이지 배치를 바꾼다.

## 6. 확대/맞춤

지원 모드:

- 원본 크기
- 창에 맞춤
- 가로폭 맞춤
- 세로높이 맞춤
- 사용자 확대율

입력:

- 마우스 휠
- Ctrl + 휠 또는 설정 가능한 확대 입력
- 드래그 팬
- 더블클릭 확대/복원 옵션

## 7. 이미지 품질

기본 품질 모드:

- 빠른 표시
- 고품질 표시

고품질에서는 SkiaSharp 또는 동급 렌더러의 고품질 보간을 사용한다.

후속 기능으로 Lanczos 계열 리샘플링 또는 별도 고품질 확대 경로를 검토한다.

주의:

- 일반 리샘플링은 원본에 없는 디테일을 생성하지 않는다.
- AI 업스케일은 별도 기능으로 취급하며 초기 버전에서 필수로 하지 않는다.

## 8. 만화 프리로드/캐시

현재 페이지 주변을 프리로드한다.

예:

```text
현재: 10
캐시 후보: 9, 10, 11, 12
```

설정 후보:

- 프리로드 앞 페이지 수
- 프리로드 뒤 페이지 수
- 최대 이미지 캐시 메모리

LRU 방식 또는 동등한 제한 캐시를 권장한다.

## 9. 만화 진행 위치

저장:

- 마지막 페이지 인덱스
- 세로 스크롤 모드일 경우 스크롤 위치 또는 기준 페이지

재오픈 시:

- 이어보기
- 처음부터

사용자 설정으로 기본 동작을 정할 수 있다.

## 10. 영상 플레이어 엔진

초기 후보는 LibVLCSharp/libVLC다.

목표는 코덱을 직접 구현하는 것이 아니라 검증된 재생 엔진 위에 Random Multimedia Manager의 UX를 구축하는 것이다.

실제 구현 전:

- 현재 안정 버전
- WPF 통합 방식
- 하드웨어 디코딩
- 외부 자막
- 비디오 출력 경로
- RTX VSR 연동 시 제약

을 다시 검증한다.

## 11. 영상 기본 기능

필수:

- 재생 / 일시정지
- 정지
- Seek
- 현재 시간 / 전체 시간
- 볼륨
- 음소거
- 배속
- 전체화면
- 프레임/시간 이동 단축키 후보
- 현재 오디오 트랙 선택
- 현재 자막 트랙 선택
- 외부 자막 불러오기

## 12. 영상 이어보기

주기적으로 또는 안전한 상태 전환 시 `VideoPositionMs`를 저장한다.

재오픈 시:

```text
마지막 위치에서 이어보기
처음부터 보기
```

기본 동작은 설정 가능하게 한다.

영상이 거의 끝난 지점에서 종료된 경우 이어보기 대신 처음부터 처리하는 임계값 옵션은 후속 기능으로 둘 수 있다.

## 13. 자막

필수 외부 자막:

- SRT
- SMI/SAMI

추가 권장:

- ASS
- SSA
- VTT

### 자동 검색

영상 파일과 같은 폴더에서 기본 이름이 같은 자막을 우선 검색한다.

예:

```text
movie.mkv
movie.srt
movie.smi
movie.ko.srt
```

### 자막 인코딩

특히 오래된 한글 SMI의 CP949/EUC-KR 계열 문제를 고려한다.

자동 감지 또는 사용자 지정 인코딩 fallback을 제공할 수 있는 구조로 한다.

### 자막 표시 설정

가능한 범위:

- 글꼴
- 크기
- 위치
- 테두리/그림자
- 자막 싱크 ±ms

엔진 자체 스타일을 강제로 덮어써서 ASS 고유 스타일을 망가뜨리지 않도록 구분한다.

## 14. 오디오

- 볼륨 저장 여부 옵션
- 음소거
- 오디오 트랙 선택
- 출력 장치 선택은 후속 기능 후보

`전체 숨김 + 음소거` 기능에서는 최소한 현재 앱의 영상 오디오가 즉시 음소거되어야 한다.

## 15. 하드웨어 디코딩

가능하면 기본 활성화하되 시스템/드라이버/코덱 호환성에 따라 fallback할 수 있어야 한다.

UI 옵션 예:

```text
하드웨어 디코딩
- 자동
- 사용
- 사용 안 함
```

## 16. RTX Video Super Resolution

RTX VSR은 영상 플레이어 기본 기능과 분리된 선택 기능으로 구현한다.

UI 목표:

```text
RTX Video Super Resolution
- 사용 안 함
- 자동
- 사용
```

지원되지 않는 시스템에서는 비활성화하고 이유를 표시한다.

구현 단계에서 NVIDIA RTX Video SDK의 최신 지원 조건과 렌더링 API 제약을 공식 문서로 다시 확인한다.

중요 설계 원칙:

- VSR 실패가 일반 영상 재생 실패로 이어져서는 안 됨
- 일반 재생 경로가 항상 fallback으로 존재해야 함
- 디코더와 렌더러 사이의 프레임 경로가 VSR 통합을 막지 않도록 초기 아키텍처에서 분리 고려

## 17. 전체화면 UX

전체화면에서는 미디어가 화면 중심을 차지한다.

- 마우스 이동/키 입력 시 컨트롤 표시
- 일정 시간 입력 없으면 컨트롤 자동 숨김
- Esc로 전체화면 종료
- 공통 랜덤/즐겨찾기/삭제 단축키는 전체화면에서도 동작
- 긴급 단축키는 최우선 처리

## 18. 오류 처리

### 만화

- 압축 열기 실패
- 암호화 ZIP
- 이미지 Entry 없음
- 손상 이미지

### 영상

- 지원하지 않는 코덱
- 파일 손상
- 디코더 초기화 실패
- 자막 로드 실패
- 하드웨어 디코딩 실패

가능한 경우 일반 fallback을 시도하고, 실패 시 공통 오류 UI에서 다음 랜덤/탐색기/랜덤 제외/삭제로 이동할 수 있게 한다.

## 19. 성능 기준

- 만화 페이지 전환 시 압축 전체 재처리 금지
- 이미지 프리로드는 취소 가능해야 함
- 다음 파일로 이동하면 이전 미디어의 불필요한 비동기 작업 취소
- 영상 재생 UI 스레드가 디코딩 작업에 장시간 블록되지 않아야 함
- 대용량 파일에서도 전체 파일을 메모리에 적재하지 않음
