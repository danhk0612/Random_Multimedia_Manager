## 해석 및 설계 경계

- 감상 기본 처리는 성공적으로 열린 미디어에 적용한다. 열기 실패는 기존 R08에 따라 감상으로 기록하지 않는다. 기록 확정 시점은 항목을 벗어날 때이며, 이번 기록 제외는 1회만 억제한다.
- 이름 변경도 경로가 달라진 경우 이전 상태를 새 항목에 자동 승계하지 않는 방향으로 설계한다. 자동 fingerprint 병합은 초기 구현하지 않는다.
- 분류별 상태 분리는 물리 파일 복제를 뜻하지 않는다. 실제 파일을 삭제하면 다른 분류에서도 파일이 사라진다. 같은 PathKey의 모든 분류 기록/진행을 제거하고 Missing으로 표시한다. 선호·영구 제외는 보존한다.
- 휴지통 실패 시 임의 영구 삭제로 전환하지 않는다. 실제 삭제 실패 시 기존 기록을 제거하지 않는다.
- 빠른 종료도 기록 제외 명령이 아니므로 D02의 기본 감상 원칙을 적용하는 방향으로 설계한다. 숨김만 수행한 경우에는 감상이 계속되므로 기록을 확정하지 않는다.
- 숨김 후 종료는 종료 기능의 순서다. 별도의 숨김/복원 기능과 혼동하지 않는다. 강제 Kill이나 일정 시간 후 강제 종료를 기본으로 추가하지 않는다.
- 위임은 기존 요구사항 안의 세부값/동작 결정에 한정한다. 아래 후순위 기능을 새로 구현할 권한을 뜻하지 않는다.
- Windows 세부 버전 및 네이티브 패키지 포함 가능 여부는 T18에서 검증한다. exe/압축 배포 승인은 단일 exe에 모든 파일을 포함할 수 있다는 보장이 아니다.

## T02 설계 결정과 근거 (2026-09-07)

| 결정 | 근거 |
|---|---|
| 분류+정규화 경로 키, 소스 포함 관계 계산 | 중첩 소스가 기록/확률을 복제하지 않으며 분류 상태 분리 유지 |
| 정확히 D×24시간 경과 시 허용, 0일은 기록 조건만 생략 | DST/날짜 경계의 모호성 제거 |
| 후보 소진 시 안내·현재 유지 | 미승인 자동 완화나 세션 재시작 방지 |
| 재방문마다 새 VisitId/Pending, 준비→저장→활성 | 기본 감상 원칙과 전환 실패 시 기존 방문 보존 |
| 수동 열기는 cursor 뒤 삽입, Forward 보존 | 기존 경로 우선 요구 유지 |
| 기록과 진행 독립, Resume 기본·5초 변경 checkpoint | 이번 제외가 이어보기를 지우지 않으며 쓰기량 제한 |
| 삭제 저널+DB 멱등 표식, 불명 결과 격리 | OS 삭제와 DB 사이 실패를 성공으로 추정하지 않고 회복 |
| AppSettings SQLite, 사용자 LocalAppData 저장 | 설정 원자성, 설치 폴더 쓰기 권한 의존 제거 |
| 메모리 세션 10000 슬롯/Seen 상한 | 무한 리소스 보유 방지, 중복 방지를 깨는 임의 잘라내기 금지 |
| T03 Core/정책 테스트 분리, App 내 직접 SQL | Windows 렌더러 없이 정책 검증, 불필요한 프로젝트·ORM 방지 |

모든 수치는 기존 범위 안의 위임 기본값이다. 경로 미지원 범위·동일 경로 재등장/내용 교체·삭제 성공 불명의 한계도 상세 계약에 명시했다. T02 정책 미결정 차단은 없다. 후속 코드는 T01 실제 Windows 검증 완료와 T02 계약 통합 후 진행한다.

## 기존 문서의 제안·후순위 보존 목록 (구현 승인 아님)

- 랜덤: 분류별 override, 즐겨찾기 3모드 랜덤 필터, 가중치/분류 균등, 후보 소진의 오래된 기록부터 완화, 세션 복원.
- 데이터/관리: 부분 fingerprint, 자동 이동 병합, 기록/진행 개별 초기화, 설정/DB 백업·복구, 상세 경로 로깅 옵션.
- 만화: RAR/CBR/7z/이미지 폴더, 세부 이미지 형식 범위, 프리로드 수/캐시 용량 UI, 빠른/고품질 모드 전환, Lanczos 별도 경로, 더블클릭 확대.
- 영상: ASS/SSA/VTT, 자막 스타일/싱크 옵션, 프레임 단위 이동, 출력 장치, 끝부분 진행 자동 초기화, 하드웨어 디코딩 선택 UI, VSR 자동/사용/미사용 UI.
- 일반: 테마, 창/분류 선택 복원 설정, Windows 자동 시작 등록, 키 녹화/기본값 복원, 알림/토스트, 업데이트 방식, 메타데이터 추가 표시, 간단 통계.
- 초기 비범위: AI 만화 업스케일·자동 분류, 고급 태그/중복 분석/대시보드, 온라인 메타데이터 수집, 미디어 서버·네트워크 스트리밍·DLNA/Chromecast·클라우드·계정·모바일.

후보를 구현하려면 사용자 승인 및 별도 Task가 필요하다. 구조를 미리 일반화하지 않는다.

## T03 승인 보완

동일 VisitId의 서로 다른 전체 저장 payload를 검증하기 위해 VisitCommit 검증값 테이블을 v1에 추가하도록 사용자가 승인했다. 방문 진행 원문을 이력에 중복 저장하지 않고 요청 해시만 저장하며, 기록 제외 방문도 멱등 검증한다. 삭제 정리 시 제거한다. 기존 감상/랜덤/진행 정책은 유지한다. 상세 형식과 경계는 DATA_AND_RANDOM_POLICY의 T03 승인 보완을 따른다.
