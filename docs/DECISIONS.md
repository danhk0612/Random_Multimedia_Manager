# 미확정 결정 및 후보

## 이번 지시와 기존 문서의 충돌 처리

| 기존 단정 | 현재 처리 |
|---|---|
| 삭제 기본 매번 확인 | 기본값 미확정(D05) |
| Fast Exit은 정상 종료, Pending 기본 폐기 | 종료 수준과 기록/진행 저장 모두 미확정(D03) |
| 숨김 시 pause·작업표시줄 제거·같은 키 복원 | 미확정(D04) |
| 트레이 유지/숨김과 복원 상태 옵션 확정 | 옵션 범위와 기본값 미확정(D04) |
| 전역 긴급키 필수 | 빠른 접근은 필수, 정확한 전역 적용 범위/기본키는 미확정(D03/D04) |
| VSR 프레임 파이프라인 선행 분리 | 기본 플레이어 후 검증(T19), 선행 구현하지 않음 |

기존 확정 중 충돌하지 않는 다중 폴더·다중 분류/혼합·세션 중복 방지·영구 랜덤 제외·Pending 기록·이어보기 분리는 REQUIREMENTS에 보존했다.

## 사용자 결정이 필요한 항목

| ID | 결정 | 막는 Task |
|---|---|---|
| D01 | 기본 제외 기간, 0일 허용/의미, 후보 소진 시 기간 완화 여부·자동 처리, 분류별 override 노출 | T02/T06 |
| D02 | 파일이 여러 분류에 속할 때 기록·즐겨찾기 공유 의미, 이동/이름 변경 시 기록 승계 범위, 이전/다음 재감상 기록, 실패 전환 시 현재 감상 유지 | T02 |
| D03 | 빠른 종료의 정상/긴급/강제 수준, Pending·진행 위치 처리, 전역 범위·기본 키·활성화 | T14/T16 |
| D04 | 숨김 시 pause, 작업표시줄/트레이, 복원키/경로, 음소거·재생·창 복원; 트레이 메뉴·클릭·최소화·닫기·시작 기본값 | T14/T15/T16 |
| D05 | 삭제 기본값과 확인 방식, 삭제 후 자동 다음 이동, 과거 기록/진행 보존 또는 제거 | T12 |
| D06 | 만화 기본 표시/읽기 방향, 표지 단독, 스크롤 여백, 휠/확대 입력 | T08 |
| D07 | 이어보기 자동/질문, 자막 자동 선택 우선순위·표시 기본값, 수동 열기의 감상 기록 포함 | T10/T11/T17 |
| D08 | Windows 지원 범위, Portable/Installer 우선순위 | T18 |
| D09 | RTX VSR 실제 통합 시점·방식·지원 범위 | T19 이후 |

D02는 기존 설계안의 파일 식별·분류 관계와 세션 전환에서 추가로 드러난 빈틈이다. 새 기능 요청이 아니라 기존 기능의 데이터 의미 결정이다. 지금 모두 답할 필요는 없으며 해당 Task 전에 확정한다.

## Astra가 근거를 남겨 정할 기술 사항

SQLite 접근 라이브러리/스키마/마이그레이션·설정 저장 위치, 기간 경계의 UTC/시간 계산, 파일 정규화 및 보수적 재식별, 세션 메모리/영속 범위, 공통 감상 인터페이스, 패키지 버전과 네이티브 배포 방식. 사용자 UX를 바꾸는 부분은 위 결정과 함께 확인한다.
기본 창 크기는 셸 구현 값일 뿐 최종 UI 결정이 아니다. 최종 디자인/아이콘·로그 방식은 필요한 작업에서 정한다.

## 기존 문서의 제안·후순위 보존 목록 (구현 승인 아님)

- 랜덤: 분류별 override, 즐겨찾기 3모드 랜덤 필터, 가중치/분류 균등, 후보 소진의 오래된 기록부터 완화, 세션 복원.
- 데이터/관리: 부분 fingerprint, 자동 이동 병합, 기록/진행 개별 초기화, 설정/DB 백업·복구, 상세 경로 로깅 옵션.
- 만화: RAR/CBR/7z/이미지 폴더, 세부 이미지 형식 범위, 프리로드 수/캐시 용량 UI, 빠른/고품질 모드 전환, Lanczos 별도 경로, 더블클릭 확대.
- 영상: ASS/SSA/VTT, 자막 스타일/싱크 옵션, 프레임 단위 이동, 출력 장치, 끝부분 진행 자동 초기화, 하드웨어 디코딩 선택 UI, VSR 자동/사용/미사용 UI.
- 일반: 테마, 창/분류 선택 복원 설정, Windows 자동 시작 등록, 키 녹화/기본값 복원, 알림/토스트, 업데이트 방식, 메타데이터 추가 표시, 간단 통계.
- 초기 비범위: AI 만화 업스케일·자동 분류, 고급 태그/중복 분석/대시보드, 온라인 메타데이터 수집, 미디어 서버·네트워크 스트리밍·DLNA/Chromecast·클라우드·계정·모바일.

후보를 구현하려면 사용자 승인 및 별도 Task가 필요하다. 구조를 미리 일반화하지 않는다.
