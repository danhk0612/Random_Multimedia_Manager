# 결정사항 / 가정 / 미확정 항목

이 문서는 새 Work가 임의로 제품 정책을 바꾸지 않도록 현재 상태를 구분한다.

## 1. 확정된 제품 방향

- Windows 데스크톱 애플리케이션
- 로컬 만화/영상 라이브러리 관리
- 분류 타입은 Comic / Video
- 하나의 분류에 여러 폴더 등록 가능
- 여러 분류 동시 랜덤 선택 가능
- Comic + Video 혼합 랜덤 허용
- 자체 만화 뷰어 / 자체 영상 플레이어 사용
- 최근 감상 기록이 있는 항목은 설정 기간 동안 랜덤에서 제외
- 현재 RandomSession에서 신규 랜덤 중복 방지
- 즐겨찾기
- 랜덤 대상 영구 제외
- 이번 감상 기록 제외
- 이전/다음 RandomSession 이동
- 파일 삭제
- 삭제 방식 옵션화
- SRT/SMI 자막 지원
- RTX VSR 지원 목표
- 전역 `Fast Exit`
- 전역 `Quick Hide + mute`
- 시스템 트레이 기능 및 옵션
- GitHub 저장소를 기준으로 개발

## 2. 확정된 기록 정책

- 파일 open 즉시 ViewHistory 확정하지 않음
- Pending 상태 사용
- 파일을 벗어날 때 기록 확정
- `이번 감상 기록 제외`는 현재 1회 기록만 억제
- 과거 기록 삭제하지 않음
- 삭제 성공한 현재 파일은 새 감상 기록을 남기지 않음
- ViewHistory와 PlaybackProgress는 분리
- Quick Hide는 ViewHistory 확정 이벤트가 아님
- Fast Exit 시 현재 Pending 기록은 기본적으로 확정하지 않음

## 3. 확정된 삭제 방향

지원 정책:

- 매번 확인
- 휴지통으로 이동
- 영구 삭제

초기 기본값:

- 매번 확인

실제 파일 작업이 성공한 뒤 DB를 반영한다.

## 4. 확정된 Quick Hide 방향

- 모든 프로그램 창 숨김
- 영상 일시정지
- 앱 음소거
- 작업표시줄 표시 제거
- 트레이 아이콘 유지/숨김 선택 가능
- 트레이 아이콘까지 숨기는 것은 복원 전역 단축키가 정상 등록된 경우만 허용
- 복원 방식은 같은 전역 단축키 또는 트레이 메뉴
- 복원 후 재생/음소거/창 상태 처리 정책은 옵션화

## 5. 확정된 Fast Exit 방향

의미:

- 사용자 확인창 없이 즉시 앱 종료
- 현재 미디어 중단
- 종료 과정 최소화

안정성 원칙:

- 정상 구현을 무조건적 `Process.Kill()`로 만들지 않음
- 이미 시작된 짧은 DB transaction은 가능한 한 안전하게 마무리
- 현재 Pending ViewHistory 기본 미확정

## 6. 현재 기술 가정

아래는 아직 구현 검증 전의 기술 방향이며 제품 정책 자체는 아니다.

- C# / .NET
- WPF
- SQLite
- SkiaSharp 계열 만화 렌더링
- LibVLCSharp/libVLC 영상 재생
- NVIDIA RTX Video SDK 기반 VSR 검토

기술 검증에서 더 적합한 대안이 확인되면 변경할 수 있지만, 변경 이유와 영향은 문서에 남긴다.

## 7. 현재 기본 가정

- 초기 대상은 Windows 10/11 x64
- 초기에는 단일 사용자
- 서버/계정/클라우드 기능 없음
- 대용량 라이브러리를 고려해 DB 인덱스 기반 랜덤 선택
- 대용량 ZIP은 전체 임시 압축 해제하지 않음
- 분류별 랜덤 가중치는 초기에는 없음
- 즐겨찾기는 랜덤 확률 자체를 자동으로 높이지 않음

## 8. 아직 미확정 - 구현 전에 자연스럽게 결정 가능

다음은 현재 제품 핵심 정책에 영향을 거의 주지 않으므로 구현 단계에서 제안 후 결정 가능하다.

- 최종 UI 디자인/색상
- 앱 아이콘
- Portable / Installer 우선순위
- ORM 사용 여부
- 설정 JSON / SQLite 설정 테이블 선택
- 기본 로그 프레임워크
- 기본 창 크기
- 기본 만화 표시 모드
- 기본 읽기 방향
- 기본 자막 글꼴/크기

## 9. 아직 미확정 - 사용자 확인이 필요한 항목

구현 시점에 선택지가 실제 UX를 바꾸므로 임의 확정하지 않는다.

### 랜덤

- 기본 최근 감상 제외 기간 (예: 30일/90일)
- 후보가 0개일 때 기본 자동 완화 여부
- 분류별 override를 초기 UI부터 노출할지 여부

### 만화

- 두 페이지 모드에서 첫 표지를 단독 페이지로 취급할지
- 세로 스크롤에서 페이지 간 여백 기본값
- 확대 입력에서 `Wheel`과 `Ctrl+Wheel` 역할

### 영상

- 이어보기 질문을 항상 띄울지 자동 이어보기할지
- 거의 끝까지 본 영상의 진행 위치를 자동 초기화할 임계값
- 외부 자막 자동 선택 우선순위

### 단축키

- Fast Exit 기본 전역 단축키
- Quick Hide 기본 전역 단축키
- 전역 단축키를 기본 활성화할지 여부

### 트레이

- X 버튼 기본 동작: 종료 / 트레이 / 질문
- 최소화 기본 동작: 작업표시줄 / 트레이
- 트레이 단일/더블클릭 기본 동작

## 10. 후순위 기능으로 분류된 항목

- AI 만화 업스케일
- 분류별 랜덤 가중치/균등 랜덤
- 중복 파일 탐지
- 고급 통계
- 고급 태그 시스템
- 온라인 메타데이터 수집

후순위라는 의미는 구조를 완전히 막아도 된다는 뜻은 아니지만, 초기 구현 복잡도를 늘리면서 미리 구현하지 않는다.

## 11. 정책 변경 규칙

제품 정책을 변경할 경우:

1. 변경 이유 확인
2. 영향 범위 확인
3. 관련 문서 수정
4. 코드/테스트 수정
5. 커밋 또는 PR에 변경사항 기록

코드만 조용히 기존 문서와 다르게 만드는 것을 피한다.
