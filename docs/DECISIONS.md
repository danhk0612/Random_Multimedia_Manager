## 해석 및 설계 경계

- 감상 기본 처리는 성공적으로 열린 미디어에 적용한다. 열기 실패는 기존 R08에 따라 감상으로 기록하지 않는다. 기록 확정 시점은 항목을 벗어날 때이며, 이번 기록 제외는 1회만 억제한다.
- 이름 변경도 경로가 달라진 경우 이전 상태를 새 항목에 자동 승계하지 않는 방향으로 설계한다. 자동 fingerprint 병합은 초기 구현하지 않는다.
- 분류별 상태 분리는 물리 파일 복제를 뜻하지 않는다. 실제 파일을 삭제하면 다른 분류에서도 파일이 사라진다. 같은 PathKey의 모든 분류 기록/진행을 제거하고 Missing으로 표시한다. 선호·영구 제외는 보존한다.
- 휴지통 실패 시 임의 영구 삭제로 전환하지 않는다. 실제 삭제 실패 시 기존 기록을 제거하지 않는다.
- 빠른 종료도 기록 제외 명령이 아니므로 D02의 기본 감상 원칙을 적용하는 방향으로 설계한다. 숨김만 수행한 경우에는 감상이 계속되므로 기록을 확정하지 않는다.
- 숨김 후 종료는 종료 기능의 순서다. 별도의 숨김/복원 기능과 혼동하지 않는다. 강제 Kill이나 일정 시간 후 강제 종료를 기본으로 추가하지 않는다.
- 위임은 기존 요구사항 안의 세부값/동작 결정에 한정한다. 아래 후순위 기능을 새로 구현할 권한을 뜻하지 않는다.
- Windows 세부 버전 및 네이티브 패키지 포함 가능 여부는 T18에서 검증한다. exe/압축 배포 승인은 단일 exe에 모든 파일을 포함할 수 있다는 보장이 아니다.

## D06 만화 표시·조작 기본값 (T08, 2026-09-09)

D06 위임 범위에서 T08의 초기 기본값을 다음으로 확정한다.

- 표시 모드: 한 페이지.
- 읽기 방향: 왼쪽→오른쪽. 두 페이지 모드는 읽기 방향에 따라 좌우 배치를 반전한다.
- 맞춤: 창 맞춤.
- 확대 입력: Ctrl+마우스 휠. 확대율 범위는 10%~800%이며 사용자 확대에 들어가면 Custom 모드로 전환한다.
- 일반 마우스 휠: 한/두 페이지에서는 이전·다음 페이지, 세로 연속 모드에서는 세로 진행 위치 이동.
- 팬: 마우스 왼쪽 드래그.
- 렌더링 품질: SkiaSharp Mitchell-Netravali cubic sampling을 기본 고품질 경로로 사용한다. 별도 빠른/고품질 전환 UI는 후순위 후보로 유지한다.
- 제한 캐시: 현재 페이지 기준 앞 1페이지, 뒤 2페이지를 비동기 프리로드하고 디코딩 이미지 캐시는 256 MiB LRU 상한을 둔다. 설정 UI는 T08 범위에 포함하지 않는다.
- Ready: ZIP/CBZ `Opened`만으로 Ready가 아니며 복원 대상 시작 페이지가 실제 디코딩된 뒤에만 Ready다.
- 진행 반환: Core의 `PlaybackProgress.Comic(page, offset)`을 그대로 사용하며 DB 저장/공통 감상 연결은 T11에 남긴다.

이 기본값은 기존 요구사항 안의 세부 선택이며 AI 확대, 추가 압축 형식, 전역 단축키, DB/랜덤 정책을 확장하지 않는다.


## T10 D07 자막 기본값 (2026-09-09)

D07의 자막 세부값은 T10 위임 범위에서 다음과 같이 확정한다.

- 자동 검색 범위는 영상 파일과 **같은 폴더**뿐이다. 영상 기본 이름과 정확히 같은 자막(`movie.srt`, `movie.smi`) 또는 기본 이름 뒤에 점 접미사가 붙은 자막(`movie.ko.srt`)만 후보로 본다. `movie2.srt`처럼 단순 접두사만 같은 파일은 후보가 아니다.
- 후보 우선순위는 `정확한 이름 SRT → 정확한 이름 SMI → 점 접미사 SRT → 점 접미사 SMI`다. 같은 우선순위 안에서는 파일명 대소문자를 무시한 오름차순으로 고정한다.
- 복수 후보가 있으면 첫 후보 하나만 자동 선택한다. 나머지는 영상 UI에서 수동 선택한다. `ko/kor` 같은 언어 접미사를 해석해 사용 언어를 추측하거나 사용자 로캘에 따라 순서를 바꾸지 않는다.
- 수동 로드는 로컬 SRT/SMI 파일을 선택할 수 있다. 자동 검색 폴더 밖의 파일도 수동 선택은 허용한다. ASS/SSA/VTT는 T10 범위에 추가하지 않는다.
- 자막 끄기는 현재 LibVLC 자막 트랙을 `-1`로 선택해 표시를 끈다. 이 선택을 DB/공통 세션 설정으로 저장하지 않는다.
- SRT는 BOM 유무와 관계없이 **엄격한 UTF-8**만 기본 지원한다. UTF-8로 해석되지 않는 SRT를 임의로 CP949로 추측하지 않고 자막 실패로 안내한다.
- SMI는 먼저 엄격한 UTF-8로 읽고, 실패하면 엄격한 Windows-949(CP949)로 읽는다. 일반 EUC-KR 바이트 범위는 CP949의 호환 범위로 처리한다. CP949/EUC-KR SMI는 원문과 SYNC 마크업을 유지한 UTF-8 임시 SMI로 변환해 LibVLC에 전달한다.
- 변환 임시 파일은 해당 `PreparedVideo`가 소유하고 영상 해제 뒤 삭제한다. 자막 변경을 위해 영상 Media/MediaPlayer/디코더를 재생성하지 않는다.
- 자동 검색·인코딩·자막 추가 실패는 자막 결과/안내일 뿐이다. 이미 성립한 영상 Ready, 현재 방문 토큰, 재생/일시정지 상태, 장치 부재 영상 전용 정책, 완료 위치 복원 상태를 실패로 바꾸지 않는다.

자막 스타일·싱크 보정 UI·인코딩 수동 선택은 후순위 목록 그대로이며 T10에서 추가하지 않는다.


## T05 초기 인덱싱 확장자 결정

사용자가 T05의 영상 확장자 미확정 보고를 검토·처리하도록 요청하여 Astra에서 초기 스캔 범위를 확정한다. 과거 PRODUCT_SPEC의 예시 자체를 승인 근거로 삼지 않고 이번 결정으로 명시한다.

- Comic: `.zip`, `.cbz`.
- Video: `.mp4`, `.mkv`, `.avi`, `.webm`, `.mov`, `.wmv`, `.m4v`, `.ts`.
- 파일명의 마지막 확장자를 OrdinalIgnoreCase로 비교한다. `.MP4`는 포함하고 `.mp4.tmp`는 포함하지 않는다. 폴더명이나 파일명 중간 문자열로 판별하지 않는다.
- 이 목록은 인덱싱 대상 필터이며 해당 확장자의 모든 코덱·내용에 대한 재생 성공 보장이 아니다. 스캔 중 디코더 실행·미디어 준비/재생·감상 기록 생성을 하지 않는다. 실제 열기 실패는 기존 T02/R08 정책에 따라 새 감상 기록 없이 처리한다.
- 목록 밖 파일·확장자 없는 파일과 자막 파일은 미디어 항목으로 신규 등록하지 않는다. 자동 내용 탐지·사용자 확장자 설정 UI·추가 포맷 지원은 이번 결정에 포함하지 않는다. 자막 검색/로드는 T10의 별도 책임이다.
- 확장자 불일치나 소스 비활성/제거는 물리 부재가 아니다. 이미 저장된 항목의 기록/진행을 지우거나 확장자 필터만으로 Missing 처리하지 않는다. 기존 경로 관찰·정규화·부분 실패 정책은 그대로 따른다.

목록의 단일 기준은 이 절이다. T05는 기존 저장 API와 스키마를 유지하며 이 결정 반영 후 재개할 수 있다.
