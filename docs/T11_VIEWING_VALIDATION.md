# T11 공통 감상 검증

## 구현과 경계

`App/Viewing/ViewingWindow`는 T06 `SessionCoordinator`를 호출한다. `ViewingMediaPreparer`/`ViewingMedia`가 Session/Operation/Item/Visit 토큰을 기존 PreparedComic/PreparedVideo에 연결한다. 영상 출력 패널은 준비부터 해제까지 같은 WPF 트리에 유지하며 HWND를 이동하지 않는다. 만화는 기존 ComicViewerWindow의 표시·조작 콘텐츠를 호스트에 넣고 준비 객체를 넘긴다. 새 파일을 다시 열지 않는다.

분류 다중 선택, 랜덤 시작, 이전/다음, 항목별 즐겨찾기·영구 제외, 방문별 이번 제외, 0~36500일 설정, 이어보기/처음부터를 연결한다. 초기 설정은 DB의 7일/Resume이다. 설정은 다음 준비부터 적용한다. 영상의 재생/일시정지/정지·탐색·볼륨/음소거·배속·트랙·외부 자막과 기존 만화 표시/확대/방향을 유지한다.

UI 명령과 checkpoint는 Dispatcher에서 동기적으로 Busy를 선점하여 중복 명령을 큐에 넣지 않는다. 이미 시작한 만화 페이지 이동은 최종 캡처 전에 완료를 기다린다. 5초마다 변경된 최신 위치 하나를 저장하며 pause/stop에서도 저장한다. 전환/닫기는 T06의 최종 진행+기록 원자 저장을 사용한다. SaveFailed/CommitUnknown에서는 FrozenCommit을 유지하고 재시도 또는 확인된 rollback의 감상 복귀를 제공한다. 창은 LeaveAsync 성공 뒤 닫는다.

감상 창은 메인 창의 모달 창이다. 진행 중 스캔이 있으면 완료 후 열도록 안내하고 감상 중에는 메인 스캔/편집을 실행할 수 없다. 따라서 스캔 반영은 세션의 최종 진행 저장·해제 이후에 실행되며 내용 교체로 삭제한 진행을 이전 checkpoint가 되살리지 않는다. DB/스캔 API 및 스키마는 변경하지 않는다. 비모달 동시 스캔은 이번 구현 범위에 포함하지 않는다.

실제 삭제, 파일 목록, 자동 감지, 트레이/전역 단축키/빠른 숨김·종료는 구현하지 않는다. Hide/일시정지/영상 끝 자체는 Leave를 호출하지 않는다. 기존 독립 만화/영상 검증 창 진입은 보존한다.

## 최종 확인 전 수동 검증 절차 (2026-09-19)

아래 재개 당시의 대기 문구는 최종 검증 정리로 대체되었다. 절차는 재검증 참고용으로 보존한다.

사용자 지시에 따라 AVI 무음 조사는 보류한다. AVI AVFormat 수정은 유지한다. 실제 제품 Windows 오디오 세션 음소거와 외부 비활성 창 자동 음소거 프로그램 사용은 확인됐으나 영상별 차이 및 최종 해결은 미확정이다. 추가 무음 진단을 T11 나머지 검증의 선행 조건으로 요구하지 않는다.

혼합 선택/화면 등 이전 정상 보고를 그대로 보존하고, 만화 후보 없음은 스캔 후 해결된 것으로 기록한다. 과거 보고의 번호를 이 문서 표의 항목과 임의로 대응하지 않는다.

우선 공통 감상 창에서 다음을 확인한다. 같은 항목을 다시 선택하기 쉽도록 테스트 분류에는 미디어 1개를 두고 기록 제외 기간을 0일로 설정한다.

1. 이어보기: 만화 후반 페이지 또는 영상 중간으로 이동 → 6초 대기 → 감상 창 정상 닫기 → 재진입. 위치 복원 후 처음부터 설정으로 재진입하면 시작 위치여야 한다. 만화와 영상을 각각 확인한다.
2. 이번 제외: ON → 다음 → 이전. 돌아온 새 방문은 OFF여야 한다. 과거 기록 보존은 기존 자동 DB 검사로 검증됐다.
3. 선호/영구 제외: 즐겨찾기와 영구 제외 ON → 다른 항목으로 전환 → 이전으로 복귀 가능. 창을 닫고 새 랜덤에서는 제외된 항목이 나오지 않아야 한다. 영구 제외만 해제하면 후보에 복귀하고 즐겨찾기는 유지돼야 한다. 제외 해제는 이전 경로로 접근 가능한 동안 수행한다.
4. 정상 닫기: 감상 중 X 한 번으로 닫히고 재진입 가능해야 한다. 후보 없음/감상 전 한 번 닫기는 수정 및 자동 회귀가 통과했다.

위 네 항목 외 준비 실패/취소·누출, 최소화/전체화면, 스캔 순서 등은 앞 표의 미검증 상태를 유지한다. 이번 재개는 수동 검증 생략이나 T11 완료 승인을 뜻하지 않는다. 제품 코드를 변경하지 않았으므로 기존 Windows 자동 검사를 불필요하게 재실행하지 않는다.

## T11 최종 검증 정리 (2026-09-19)

사용자는 ‘테스트 하기 힘들거나 불가한 부분 제외하고 기본적인 작동은 확인했어’라고 보고했다. 기본 동작은 사용자 확인 완료로, 어렵거나 불가능한 추가 수동 검사는 사용자 보고에 따라 생략·미검증으로 남기고 T11 구현/검증을 마무리한다. 항목별 결과가 별도로 제공되지 않았으므로 이전 수동 표 전체를 통과로 바꾸지 않는다. 준비 실패/취소·누출 등 개별 미확인 항목에는 기존 자동 검사 근거만 적용한다. AVI 무음 조사는 보류이며 해결로 표기하지 않는다. 다음 전환 지연 보완은 별도 사용자 정상 확인을 유지한다.
