# T11 공통 감상 검증

## 구현과 경계

`App/Viewing/ViewingWindow`는 T06 `SessionCoordinator`를 호출한다. `ViewingMediaPreparer`/`ViewingMedia`가 Session/Operation/Item/Visit 토큰을 기존 PreparedComic/PreparedVideo에 연결한다. 영상 출력 패널은 준비부터 해제까지 같은 WPF 트리에 유지하며 HWND를 이동하지 않는다. 만화는 기존 ComicViewerWindow의 표시·조작 콘텐츠를 호스트에 넣고 준비 객체를 넘긴다. 새 파일을 다시 열지 않는다.

분류 다중 선택, 랜덤 시작, 이전/다음, 항목별 즐겨찾기·영구 제외, 방문별 이번 제외, 0~36500일 설정, 이어보기/처음부터를 연결한다. 초기 설정은 DB의 7일/Resume이다. 설정은 다음 준비부터 적용한다. 영상의 재생/일시정지/정지·탐색·볼륨/음소거·배속·트랙·외부 자막과 기존 만화 표시/확대/방향을 유지한다.

UI 명령과 checkpoint는 Dispatcher에서 동기적으로 Busy를 선점하여 중복 명령을 큐에 넣지 않는다. 이미 시작한 만화 페이지 이동은 최종 캡처 전에 완료를 기다린다. 5초마다 변경된 최신 위치 하나를 저장하며 pause/stop에서도 저장한다. 전환/닫기는 T06의 최종 진행+기록 원자 저장을 사용한다. SaveFailed/CommitUnknown에서는 FrozenCommit을 유지하고 재시도 또는 확인된 rollback의 감상 복귀를 제공한다. 창은 LeaveAsync 성공 뒤 닫는다.

감상 창은 메인 창의 모달 창이다. 진행 중 스캔이 있으면 완료 후 열도록 안내하고 감상 중에는 메인 스캔/편집을 실행할 수 없다. 따라서 스캔 반영은 세션의 최종 진행 저장·해제 이후에 실행되며 내용 교체로 삭제한 진행을 이전 checkpoint가 되살리지 않는다. DB/스캔 API 및 스키마는 변경하지 않는다. 비모달 동시 스캔은 이번 구현 범위에 포함하지 않는다.

실제 삭제, 파일 목록, 자동 감지, 트레이/전역 단축키/빠른 숨김·종료는 구현하지 않는다. Hide/일시정지/영상 끝 자체는 Leave를 호출하지 않는다. 기존 독립 만화/영상 검증 창 진입은 보존한다.

## 자동 검증

`.github/workflows/t11-viewing.yml`: Windows x64/.NET 10 Release 솔루션 빌드, Core/Data/T06 회귀, 실제 SkiaSharp/LibVLC 어댑터와 SQLite 연결 검사, 공통 WPF 창 자동 조작, 만화·영상·자막 회귀.

```powershell
dotnet build RandomMultimediaManager.sln -c Release
dotnet run --project tests/RandomMultimediaManager.Viewing.Tests -c Release
```

테스트는 임시 DB와 합성 만화/복사한 영상만 사용한다. 실제 어댑터 준비/토큰/방문, 만화↔영상/Back/Forward, 준비 실패 보존, 저장 실패/frozen/rollback, 기록 억제와 기존 이력·진행·선호 독립, 해제 후 배타 파일 열기를 검사한다. UI 자동 조작은 다중 분류·랜덤·다음·이전·checkpoint·정상 닫기를 확인한다. 사람의 화면/소리 확인과 구분한다. 최종 실행 결과는 CURRENT_STATE.md에 기록한다.

## 사용자 Windows 수동 검증 — 대기

별도 작업 폴더에서 다음을 실행한다. 기존 미커밋 작업이 있는 폴더에는 적용하지 않는다.

```powershell
git clone --branch task/t11-common-viewing-ui https://github.com/danhk0612/Random_Multimedia_Manager.git RMM-T11
cd RMM-T11
git rev-parse HEAD
dotnet --info
dotnet run --project src/RandomMultimediaManager.App -c Release
```

테스트용 ZIP/CBZ 1개와 MP4/MKV 1개를 서로 다른 폴더에 복사한다. 메인 화면에서 테스트 Comic/Video 분류를 생성하고 각 폴더를 소스로 추가하여 스캔한다. 기존 사용자 파일을 삭제/변경하지 않는다.

| 항목 | 절차 | 기대 결과 |
|---|---|---|
| 혼합/이전/다음 | 랜덤 감상 열기 → 두 분류 선택 → 랜덤 시작 → 다음 → 이전 → 다음 | 만화/영상이 바뀌고 이전/다음 경로를 재사용. 파일명/화면 일치 |
| 만화 조작 | 페이지 이동, 한/두/세로, LTR/RTL, 맞춤, Ctrl+휠, 드래그 | 기존 만화 품질/조작 유지. 후반 페이지까지 정상 |
| 영상/자막 | 재생/pause/stop, ±10초/슬라이더, 볼륨/음소거/배속, 내장 트랙, SRT/SMI 선택/수동/끄기 | 현재 영상 유지, 한글·싱크와 실제 소리 확인. 자막 실패는 영상 중단 아님 |
| 이어보기 | 후반 페이지 또는 영상 중간으로 이동 → 6초 대기 → 감상 창 정상 닫기 → 제외 기간 0 저장 → 같은 분류에서 다시 시작 | 저장된 위치로 복원. 처음부터 설정에서는 처음에서 시작 |
| 이번 제외 | 이번 제외 ON → 다음 → 이전 | 재방문 시 이번 제외 OFF. 과거 기록 삭제 여부는 자동 DB 검사 근거로 확인 |
| 선호/영구 제외 | 즐겨찾기 ON·영구 제외 ON → 다음/이전 → 감상 창 닫기 → 같은 분류에서 새 랜덤 시작 | Back은 가능, 새 랜덤은 영구 제외를 선택하지 않음. 해제 후 후보 복귀 |
| 준비 실패 | 별도 테스트 분류에 손상 ZIP 또는 손상 영상을 스캔 → 정상 항목 감상 중 해당 분류로 랜덤 시작 | 오류 안내, 기존 파일/위치/이번 제외 유지. 원래 영상 pause/play 상태 유지 |
| 준비 취소/누출 | 큰 테스트 영상 분류로 랜덤 시작 → 준비 중 취소. 소리와 화면 관찰 | 준비 대상의 화면/소리 누출 없음, 기존 감상 유지 |
| 정상 닫기 | 재생 중 감상 창 X → 다시 열기. 준비 중에도 X 시험 | 저장 후 닫힘, 재시작 가능. 테스트 복사본 파일 이름 변경 가능 |
| 최소화/전체화면 | 재생 중 최소화/복원, 전체화면/복귀 | 단순 창 표시 변경은 기록 확정하지 않음. 공통 버튼 사용 가능 |
| 스캔 순서 | 스캔 진행 중 랜덤 감상 진입, 감상 창 열린 상태에서 메인 조작 시도 | 스캔 완료 후 진입 안내, 감상 중 메인 비활성. 감상 종료 후 스캔 정상 |

저장 실패/성공 불명은 테스트 전용 commit 실패 주입과 기존 T06 자동 검사로 확인한다. 실사용 DB의 권한/파일을 바꾸어 억지로 재현하지 않는다. 직접 재현하지 못한 화면·소리 항목은 미검증으로 보고한다. T09/T10 생략 승인은 적용하지 않는다.

결과는 사용한 HEAD, 항목별 통과/실패/미검증, 실패 단계와 메시지로 전달한다.
