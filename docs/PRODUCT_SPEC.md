# 제품 요구사항 (Product Spec)

## 1. 제품 정의

Random Multimedia Manager는 Windows에서 로컬 만화/영상 파일을 분류별로 관리하고, 최근 감상 기록을 기준으로 반복을 피하면서 랜덤 감상할 수 있게 하는 전용 미디어 뷰어/플레이어다.

핵심 사용 흐름은 다음과 같다.

```text
분류 선택
→ 랜덤 후보 계산
→ 만화/영상 자체 뷰어로 감상
→ 즐겨찾기 / 랜덤 제외 / 이번 기록 제외 / 삭제
→ 이전·다음 랜덤 항목 이동
→ 감상 결과 및 이어보기 위치 저장
```

## 2. 초기 가정

- 1차 대상 OS는 Windows 10/11이다.
- 1차 버전은 단일 사용자 로컬 애플리케이션이다.
- 라이브러리는 Windows 파일 시스템 경로를 기준으로 한다.
- 클라우드 동기화, 계정, 서버 기능은 초기 범위에 포함하지 않는다.
- 만화와 영상 분류를 동시에 선택하는 것을 허용한다. 랜덤 결과 타입에 따라 해당 뷰어가 열린다.
- 삭제 기본 정책은 `매번 확인`으로 한다.
- 강제 종료 단축키는 OS 수준 프로세스 Kill이 아니라, UI 확인 없이 가능한 한 빠르게 애플리케이션을 안전 종료하는 기능으로 정의한다. 이미 커밋된 DB 상태는 보존하고 현재 Pending 감상 기록은 기본적으로 확정하지 않는다.

## 3. 주요 목표

1. 무엇을 볼지 고르는 시간을 줄인다.
2. 최근 본 파일이 짧은 기간 안에 반복되는 것을 자동 방지한다.
3. 감상 도중 파일 정리를 별도 탐색기 작업 없이 처리한다.
4. 만화와 영상을 하나의 앱에서 동일한 랜덤 세션 UX로 다룬다.
5. 대용량 라이브러리에서도 빠른 랜덤 선택과 빠른 뷰어 시작을 제공한다.

## 4. 비목표 / 후순위

초기 버전에서 다음 기능은 핵심 범위가 아니다.

- 온라인 스트리밍 서비스 연동
- 메타데이터 자동 수집/스크래핑
- 계정/클라우드 동기화
- 모바일 버전
- DLNA/Chromecast 송출
- 고급 태그 자동 분류
- AI 기반 내용 분석

## 5. 분류(Category)

각 분류는 다음 값을 가진다.

- 이름
- 타입: `Comic` / `Video`
- 소스 폴더 1개 이상
- 하위 폴더 포함 여부
- 활성/비활성
- 선택적 랜덤 제외 기간 override

하나의 분류에 여러 폴더를 등록할 수 있어야 한다.

예:

```text
애니메이션 (Video)
- D:\Media\Anime
- E:\Archive\Anime
```

## 6. 라이브러리 스캔

필수 기능:

- 최초 전체 스캔
- 수동 재스캔
- 프로그램 시작 시 빠른 변경 확인 옵션
- 실행 중 파일 변경 감지 옵션
- 새 파일 추가
- 사라진 파일 감지
- 이름 변경/이동된 파일의 재식별을 가능한 범위에서 지원

매 랜덤 선택 시 디스크 전체를 다시 검색하지 않고 SQLite 인덱스를 사용한다.

## 7. 지원 파일

### 만화

1차:

- `.zip`
- `.cbz`

확장 후보:

- `.rar`
- `.cbr`
- `.7z`
- 이미지 폴더

### 영상

영상 엔진이 안정적으로 지원하는 일반 포맷을 허용한다.

예:

- `.mp4`
- `.mkv`
- `.avi`
- `.webm`
- `.mov`
- `.wmv`
- `.m4v`
- `.ts`

## 8. 메인 화면

메인 화면의 중심은 파일 브라우저가 아니라 `랜덤 보기`다.

필수 요소:

- 분류 목록 및 다중 선택
- 선택 분류별 타입 표시
- 현재 최근 감상 제외 기간
- 랜덤 보기 버튼
- 전체 파일 수 / 현재 랜덤 후보 수 / 즐겨찾기 수 정도의 간단한 상태 표시
- 설정 진입
- 필요 시 검색/라이브러리 보기 진입

## 9. 랜덤 감상

랜덤 후보는 기본적으로 다음 조건을 모두 만족해야 한다.

- 선택한 활성 분류에 속함
- 실제 파일이 존재함
- `랜덤 대상 제외` 상태가 아님
- 최근 N일 내 감상 기록이 없음
- 현재 랜덤 세션에서 이미 새로 선택된 적이 없음

즐겨찾기 필터 옵션:

- 전체
- 즐겨찾기만
- 즐겨찾기 제외

후보가 0개인 경우:

- 안내 메시지 표시
- `가장 오래 전에 본 항목부터 허용`
- `제외 기간 변경`
- `취소`

설정에서 후보 0개 시 자동으로 오래된 기록부터 허용하는 옵션을 둘 수 있다.

## 10. 랜덤 세션

랜덤 보기 시작 시 세션을 생성한다.

예:

```text
A → K → C → M
        ↑ current
```

- `이전`은 K
- `다음`은 C
- 세션의 마지막 항목에서 `다음`을 누르면 새로운 랜덤 후보를 뽑아 세션 뒤에 추가
- 브라우저 Back/Forward와 유사한 방식으로 동작
- 현재 세션에서 새로 뽑은 항목은 중복 선택하지 않음
- 이전 세션 복원은 옵션 기능으로 둔다.

## 11. 공통 감상 컨트롤

만화/영상 모두 다음 동작을 공통 제공한다.

- 즐겨찾기 토글
- 랜덤 대상 영구 제외/복구
- 이번 감상 기록 제외 토글
- 이전 랜덤 항목
- 다음 랜덤 항목
- 파일 정보
- 탐색기에서 파일 위치 열기
- 삭제
- 전체화면

## 12. 즐겨찾기와 제외 상태

상태 의미를 명확히 분리한다.

- `즐겨찾기`: 좋아하는 파일 표시
- `랜덤 제외`: 파일은 유지하지만 랜덤 후보에서는 제외
- `이번 감상 기록 제외`: 현재 감상만 기록하지 않음
- `삭제`: 실제 파일 제거

## 13. 삭제 정책

설정 가능한 삭제 방식:

- 항상 확인
- 휴지통으로 이동
- 영구 삭제

`항상 확인`일 때 확인창 예:

```text
이 파일을 삭제하시겠습니까?
[휴지통으로 이동] [영구 삭제] [취소]
□ 앞으로 이 방식을 사용
```

삭제가 성공하면:

- 현재 파일에 대한 새 감상 기록을 확정하지 않음
- 라이브러리에서 해당 파일을 제거/삭제 상태로 반영
- 세션에서는 항목을 유지하되 `삭제됨` 상태로 표시하거나 안전하게 건너뜀
- 다음 항목으로 이동 가능

삭제 실패 시 DB에서 파일을 삭제된 것으로 확정하지 않는다.

## 14. 감상 기록

감상 기록과 이어보기 위치는 별도 데이터다.

- 감상 기록: 랜덤 재등장 제한에 사용
- 진행 위치: 만화 마지막 페이지 / 영상 재생 위치에 사용

파일을 연 순간 감상 기록을 확정하지 않는다.

현재 항목은 `Pending` 상태로 관리하고, 보통 다음 상황에서 기록을 확정한다.

- 다음 랜덤으로 이동
- 이전 랜덤으로 이동
- 뷰어 닫기
- 정상 프로그램 종료

예외:

- `이번 감상 기록 제외`가 켜져 있으면 확정하지 않음
- 파일을 삭제한 경우 확정하지 않음
- 즉시 종료 단축키 사용 시 현재 Pending 기록은 기본적으로 확정하지 않음

## 15. 이어보기

### 만화

- 마지막 페이지/스크롤 위치 저장
- 다시 열면 마지막 위치로 이어보기 또는 처음부터 보기 선택 가능

### 영상

- 마지막 재생 시각 저장
- 다시 열면 이어보기 또는 처음부터 보기 선택 가능

이어보기 위치가 저장되어 있어도 최근 감상 제외 판단과는 독립적으로 처리한다.

## 16. 라이브러리 탐색/검색

랜덤이 중심이지만 최소한의 일반 탐색을 제공한다.

- 분류별 파일 목록
- 파일명 검색
- 즐겨찾기 필터
- 랜덤 제외 필터
- 최근 감상/미감상 필터
- 수동으로 파일 열기

수동으로 연 파일을 감상 기록에 포함할지는 설정 가능하게 한다.

## 17. 파일 정보

### 공통

- 파일명
- 전체 경로
- 파일 크기
- 마지막 수정 시각
- 마지막 감상일
- 감상 횟수
- 즐겨찾기/랜덤 제외 상태

### 만화 추가 정보

- 페이지 수
- 대표 이미지 크기 또는 페이지별 크기 정보

### 영상 추가 정보

가능한 경우:

- 재생시간
- 해상도
- FPS
- 비디오 코덱
- 오디오 코덱/트랙
- 자막 트랙

## 18. 오류 파일 처리

랜덤으로 선택된 파일을 열 수 없는 경우 다음 선택지를 제공한다.

- 다음 랜덤
- 다시 시도
- 탐색기에서 보기
- 랜덤에서 제외
- 삭제

깨진 ZIP/지원하지 않는 영상/접근 권한 오류가 전체 랜덤 세션을 중단시키지 않아야 한다.

## 19. 설정 영역

### 일반

- 시작 시 마지막 창 위치/크기 복원
- 시작 시 마지막 분류 선택 복원
- 테마
- Windows 시작 시 실행

### 랜덤

- 최근 감상 제외 기간
- 후보 0개 처리
- 즐겨찾기 기본 필터
- 세션 복원 여부

### 파일/삭제

- 삭제 방식
- 삭제 확인 정책
- 수동으로 연 파일 감상 기록 여부

### 만화

- 페이지 표시 방식
- 읽기 방향
- 기본 확대 방식
- 이미지 리샘플링 품질
- 프리로드/메모리 캐시 한도

### 영상

- 기본 볼륨
- 기본 배속
- 하드웨어 디코딩
- 자막 기본 설정
- RTX VSR

### 단축키/트레이

세부 내용은 `SHORTCUTS_AND_TRAY.md`를 따른다.

## 20. 통계

낮은 우선순위지만 DB가 갖춰진 뒤 쉽게 제공할 수 있다.

- 전체 파일 수
- 분류별 파일 수
- 최근 N일 감상 수
- 미감상 수
- 즐겨찾기 수
- 랜덤 제외 수

## 21. 품질 기준

- 대용량 라이브러리에서도 랜덤 선택이 디스크 전체 탐색에 의존하지 않아야 한다.
- 뷰어/플레이어 전환 시 UI가 장시간 멈추지 않아야 한다.
- 삭제, 감상 기록, 진행 위치 저장은 서로 일관성을 유지해야 한다.
- 파일 오류 하나가 프로그램 전체 종료로 이어지지 않아야 한다.
- 전체화면에서도 핵심 단축키가 정상 동작해야 한다.
